# NumPy Lecture Notes & Practice

A beginner-friendly collection of NumPy lecture notes, Jupyter notebooks, practice questions, and solutions for learning numerical computing with Python.

This repository is designed for students learning NumPy fundamentals, array operations, indexing, broadcasting, random number generation, and linear algebra.

## 📚 Topics Covered

| Topic | Notebook |
|---|---|
| NumPy Basics | `numpy_basics.ipynb` |
| Array-Oriented Programming | `Array_Oriented_Programming.ipynb` |
| Indexing and Slicing | `indexing.ipynb` |
| Broadcasting | `broadcasting.ipynb` |
| Universal Functions (ufuncs) | `ufunctions.ipynb` |
| Linear Algebra | `linear_algebra.ipynb` |
| Pseudorandom Number Generation | `Pseudorandom_Number_Generation.ipynb` |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/alitaqishah/numpy-lecture-notes.git
```

### 2. Open the project folder

```bash
cd numpy-lecture-notes
```

### 3. Install NumPy and Jupyter

Make sure Python is installed, then run:

```bash
python -m pip install numpy jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file to explore the notes and run the examples.

You can also open the notebooks directly on GitHub to read them without installing anything.
